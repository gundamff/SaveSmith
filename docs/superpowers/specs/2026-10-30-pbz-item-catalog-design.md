# 《影之刃零》物品名称与添加功能设计

## 目标

从 Steam build `26266538` 的游戏资源中提取正式的简体中文和英文物品名称，替换当前仅展示内部 ID 后缀的占位行为，并允许玩家搜索、修改或添加武器强化材料与普通消耗品。

本变更不扩大到武器、饰品、任务物品或阈值型收集品。

## 数据来源

- 使用当前游戏资源 AES 密钥和与 build `26266538` 匹配的 USMAP，在开发期读取 `ProjectPBZ/Content/Paks` 中的 IoStore 资源。
- 从物品 DataTable、资产引用和本地化资源中关联：
  - 内部物品 ID
  - 物品类别
  - 简体中文正式名称
  - 英文正式名称
  - 游戏定义的堆叠上限
- 抽表产物整理为 SaveSmith 内置静态目录；运行时不读取游戏 PAK，不捆绑解包工具、USMAP、AES 密钥或原始游戏资产。
- 目录记录来源 build、生成步骤和输入文件哈希，便于游戏更新后重新生成。

名称随 SaveSmith 当前语言切换。简体中文缺失时回退英文，英文也缺失时明确显示“未知物品”及内部 ID，不猜测名称。

## 支持范围

### 武器强化材料

- 收录游戏目录中确认属于武器强化用途的全部材料，不再只依赖 `Weapon_Material_*` 前缀决定显示名称。
- 支持修改当前槽中已有材料数量。
- 支持按正式名称或内部 ID 搜索并添加当前槽中未拥有的材料。
- 数量范围维持 `0..9999`；超过旧 `MaxAmount` 时同步抬高 `MaxAmount`。

### 普通消耗品

- 仅收录游戏目录明确归类为普通、可堆叠、可直接消耗的背包物品。
- 支持修改已有数量，以及按正式名称或内部 ID 搜索并添加未拥有条目。
- 添加数量默认 `1`，上限采用游戏目录中的堆叠上限。

### 明确排除

- 记忆之花、黑石碎片、杀气琥珀等达到阈值后触发合成、能力或状态变化的收集品。
- 穿行符如果经目录确认属于阈值、任务或特殊状态物品，也必须排除；只有确认是普通消耗品时才进入消耗品目录。
- 武器、饰品、任务物品、钥匙、剧情道具、DLC 权利及解锁状态。

阈值型收集品不能只改数量。后续支持前必须定位数量、完成标志和效果状态，并验证真实的临界获取流程。

## 存档写入规则

添加新条目前，必须从真实存档和游戏资产验证该类别的完整 `InventoryInfos` 记录结构。不得仅复制任意现有条目后替换 ID。

- 已存在：修改原记录，不改变键集合之外的未知字段。
- 未存在：按该类别已验证的规范模板创建完整记录。
- 新记录必须生成符合游戏格式的数量、上限、首次获得时间、修改时间和周目字段。
- 同一 ID 不创建重复记录；再次添加时按数量增加处理，并执行上限检查。
- 保存前验证 ID 属于内置目录、类别受支持、数量合法、记录字段完整。
- 如果某类消耗品无法证明记录结构或副作用安全，则即使能提取名称也不进入可添加目录。

## 界面

资源页保留内部槽位选择，并将资源区域分为两个 Tab：

1. **武器强化材料**
2. **消耗品**

每个 Tab 包含：

- 已有物品表：正式名称、内部 ID、当前数量、历史/堆叠上限和数量编辑器。
- 名称或 ID 搜索。
- “添加物品”入口：可搜索下拉目录、选择数量后添加。
- 已存在物品在添加时显示为“增加数量”，不产生第二条记录。

`Player.Dust` 在中文界面显示正式游戏名称“意识尘埃”，英文名称从游戏本地化资源提取；内部字段仍保持 `Dust`。

## 错误处理

- 目录不含 ID、类别不受支持或记录模板未验证：拒绝添加。
- 数量不是整数、低于零或超过类别上限：拒绝修改。
- 当前槽结构与已验证模板不兼容：整项禁用并提示，不尝试修补。
- 游戏更新导致目录 build 不匹配时，现有白名单编辑仍按结构验证；新增目录项不得静默扩大。

## 验证

自动测试覆盖：

- 中英文名称解析、回退及按名称/ID 搜索。
- 强化材料与普通消耗品分类，阈值收集品明确排除。
- 已有条目修改、未拥有条目创建、重复添加转为数量增加。
- 类别上限、材料 `MaxAmount` 联动和非法模板拒绝。
- 未知 JSON 字段与未修改槽位保持。
- 抽表目录中 ID、名称、类别和来源元数据完整。

真机验收在备份副本上分别执行：

1. 添加一个当前槽未拥有的强化材料，游戏载入后可见并可用于强化。
2. 添加一个当前槽未拥有的普通消耗品，游戏载入后可见并可正常消耗。
3. 游戏内保存并退出，二次载入正常。
4. 再由 SaveSmith 读取游戏重写后的记录，结构和数量仍合法。

未通过对应真机验收的类别不得发布“添加未拥有物品”能力。
