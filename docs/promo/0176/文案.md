## 简介

这版主要修“点了保存没反应”这件事，顺带把影之刃零的进度编辑补齐。

新增：
- 保存成功会提示「已保存 N 个文件」；没有改动会提示「没有改动需要保存」；失败会弹出错误对话框，可复制详情
- 一键复制诊断信息：版本、系统、游戏模块、槽位、存档目录文件列表、最近错误、日志尾部
- 日志写入 `%AppData%\SaveSmith\logs\`，排查不用再靠猜

影之刃零（0.17.3–0.17.5 累积）：
- 新增 Progress 页签，BOSS 最佳时间可直接编辑
- 材料 / 消耗品 / 图鉴分页，同一页改完
- 成长与进度：等级、属性、资源直接调
- 修复 Boss 名称缺字
