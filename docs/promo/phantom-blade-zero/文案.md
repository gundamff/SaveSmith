## 简介

开源单机存档修改器「存档酱」现已支持影之刃零（Phantom Blade Zero）。

本片演示：
· 意识尘埃（Dust）直接改数量
· 武器强化材料：搜索正式中文名或 ID，添加 / 改数量 / 删除
· 养成 Tab：穿行符等可添加；黑石等累加阈值类可改但永久加成一般不生效
· 进游戏对照武器强化；保存前自动备份

说明：累加阈值类道具（如黑石碎片）实测改数量通常不会导致崩溃，但永久属性加成等效果一般不会因此生效。
后续会有更多修改内容，敬请期待。

下载：GitHub Releases 搜 SaveSmith
项目开源，欢迎提 Issue / 贡献新游戏模块。

免责声明：非官方工具，与 S-GAME Studio / S-GAME Publishing 无关联。仅供已购买正版的玩家在本地、单机环境下学习研究。修改存档有风险，请先完全退出游戏、暂时关闭 Steam 云同步，并依赖自动备份。请支持正版。当前仅验证 Steam build 26266538。
